# Changelog

## 0.3.0 - 2026-10-25

- Specialize GTA finding inside the shared Gaming workflow, with detector defaults
  and no raw options in the main flow. Sports does not offer gaming detectors.
- Recognize explicit vehicle spin-outs, limited Spanish event cues and mission /
  heist / survival-wave progress, with future, history and negation guards.
- Keep a repeated celebration in one window when no separate supported action intervenes.
- Enable existing local-model corroboration by default, with source-only fallback
  when a local model is unavailable. No additional GTA model weights are installed.
- Record real YouTube facecam stream and Twitch clip comparisons, source hashes,
  actual exports, misses and pending Eklipse baseline access.
- Improve repository discovery with GTA/Clips Kitty wording and GitHub topics.

## 0.2.0 — 2026-10-25

- Reject retellings, hypothetical plans, dreams, retractions and out-of-source evidence.
- Retain complete supported utterances and nearby setup/reaction within limits.
- Preserve distinct overlapping events; explain semantic duplicate suppression.
- Return factual titles and schema-2 reports with score components, observed
  modalities, supported utterance intervals and review warnings.
- Withhold truncated candidates from find output and avoid destructive trims.
- Add 30 original adversarial cases, 300 bounds combinations and adapter regressions.
- Pin CI to the merged SDK baseline and separate synthetic/live evidence.
- Keep Discord delivery and Twitch account operations exclusively in Clips Studio.

See docs/QUALITY_IMPROVEMENTS.md for measurements and limitations.

Initial standalone MIT plugin, deterministic GTA transcript cues, measured
supporting signals, read-only nominations and all four SDK stages.
